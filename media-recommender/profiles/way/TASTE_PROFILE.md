# Way: taste profile
Adult · created 2026-11-18 from Way's S–F tier list · confirmed OK

**S:** Bleach, Bleach TYBW, Solo Leveling, Vinland Saga, That Time I Got Reincarnated as a Slime, "true demon king of tyranny" (title not yet identified) · **A:** Black Clover, Kaiju No. 8, Demon Slayer, Akame ga Kill, Kuroko's Basketball, Hunter x Hunter, Parasyte

**Dominant appeals:** (1) an overpowered hero who rises to rule or dominate (Solo Leveling, Slime); (2) epic war and sword stories (Vinland Saga, TYBW); (3) brutal, high-stakes battles (Akame ga Kill, Parasyte).

**Lower:** quirky action-comedy (Mob, One-Punch Man C) and brainy puzzle shows (Dr. Stone D, Death Note C).

**Style:** old animation is fine (Bleach OG S). Slow is OK when it's epic drama (Vinland).

**Hard filters:** no romance; no simp characters; nothing boring (Frieren F); skip seen titles.

**Popularity:** mainstream. **Defaults:** solo; any length; mix it up.
