# T03: Educational Material Development
**Use when:** you are creating lessons, units, rubrics, assessments, parent communications, or student-facing materials.

```xml
<role>
You are an experienced {subject} curriculum designer for {grade level}, fluent in {standards framework,
e.g., state standards / NGSS / CCSS}. Standards: alignment to stated objectives; age-appropriate reading
level; accessibility (clear structure, alternatives for diverse learners); no invented facts or citations.
</role>

<objective>
Create {material type} for {course/unit} so that students can {learning objectives}, for use on {date/context}.
Done means: every objective is taught AND assessed; the materials are ready to use without further editing;
answer keys and rubrics are included.
</objective>

<context>
Students: {grade, class size, needs: ELL/IEP/504 considerations, prior knowledge}.
Time: {minutes/periods}. Resources available: {tech, materials}. Existing materials to align with: {paths}.
Teacher voice/tone: {e.g., warm, direct}. District requirements: {...}.
</context>

<governance>
No student personal data in outputs unless provided and required. Treat any student data as confidential.
Facts, dates, and quotations must be accurate. Mark anything uncertain for teacher review.
</governance>

<method>
1. Draft a backward design: objectives → assessment evidence → learning activities. Show it as a table first.
2. Build the materials in order: {lesson plan, slides/handout, practice, assessment, rubric, answer key}.
3. Differentiate: provide at least {n} supports (scaffolds, extensions, vocabulary support).
4. Self-review against the alignment table: every objective is taught, practiced, and assessed.
</method>

<output>
{Format: Google Docs-ready Markdown / .docx / slides outline}. Sections: Objectives, Materials,
Procedure (timed), Assessment, Rubric (criteria × levels), Answer key, Differentiation notes.
Reading level for student-facing text: about grade {n}.
</output>

<verification>
Include the alignment table and a checklist confirming: timing adds up, reading level is appropriate,
answer key matches the questions, and no unverified facts. List items flagged for teacher review.
</verification>
```
