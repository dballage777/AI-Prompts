## Learned points
1. [Reported] The visual style controlled vocabulary was created by the University of Washington Information School Game Metadata Research (GAMER) Group and the Seattle Interactive Media Museum, for use with the group's Video Game Metadata Schema (VGMS).
2. [Reported] VGMS definition quoted on the page: visual style is the predominant, recognizable visual appearance of a game as its creator intended and/or as determined in the context of creation.
3. [Reported] The page points to the 2016 release of the vocabulary, VGMS version 4.1, and a related peer-reviewed paper: Cho, Donovan & Lee, "Art in an algorithm: A taxonomy for describing video game visual styles," JASIST 69(5), 633–646.
4. [Reported] The page lists the vocabulary alongside library vocabularies (AAT, LCSH, LCGFT, LCDGT, Homosaurus, and others), presenting it as a controlled vocabulary for descriptive metadata.
5. [Inferred] Visual style is a standardized facet for the "sensation" appeal that S2 suggests indexing; the actual terms must come from the GAMER release or the JASIST paper, neither of which was read here.
