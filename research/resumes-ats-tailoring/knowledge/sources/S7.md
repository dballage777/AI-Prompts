## Learned points
1. Scope: O*NET calls itself "the nation’s primary source of occupational information"; the database has 900+ occupation profiles covering 55,000+ jobs; the O*NET-SOC taxonomy (aligned to 2018 SOC) has 1,016 titles, 923 with full data; free; updated quarterly. — Documented
2. Content Model scale: 19,000+ task statements linked to 2,000+ detailed work activities (DWAs), grouped into 325 intermediate and 41 generalized work activities. — Documented
3. Summary Report structure (per help page): code/title/definition; Sample of Reported Job Titles (titles given by incumbent workers); Tasks; Technology Skills (with Hot Technology and In Demand flags); Work Activities; DWAs; Work Context; Job Zone; Training & Credentials; Skills; Knowledge; Education; Abilities; Interests; Work Styles; Wages; Job Openings; Related Occupations; Professional Associations. Most sections show the top 5 with a "show all" option. — Documented
4. Definitions: Hot Technology = "technology requirements frequently included across all employer job postings"; In Demand = technology requirements "frequently included in employer job postings for a particular occupation". — Documented
5. Hot Technologies data come from Lightcast US job-postings data: 46,885,153 unique postings from 1 Jan–31 Dec 2025; 176 technologies listed. Top counts: Microsoft Office software 3,421,542; Microsoft Excel 3,211,598; Outlook 1,712,260; PowerPoint 1,618,650; Word 956,468; Python 814,960; SQL 758,250; Salesforce 581,755. — Documented
6. Worked example (Accountants and Auditors, 13-2011.00): 30 tasks (e.g., "Review accounts for discrepancies and reconcile differences."); 37 software-skill categories with Hot Technology flags (e.g., SQL, Tableau, Alteryx, Workday, Microsoft Excel/Word); 6 In Demand skills; sample titles include Cost Accountant, Internal Auditor, "CPA (Certified Public Accountant)"; 69% of respondents say a bachelor's degree is required; Job Zone Four. — Documented
7. Skills taxonomy: "Essential Skills" (e.g., Reading Comprehension, Critical Thinking, Writing, Mathematics) and "Transferable Skills" defined as "skills you can use across different jobs, such as communication, problem solving, and team work", grouped into Complex Problem Solving, Resource Management, Social and Systems skills. A Soft Skills Custom List lets users tick skills they have to find matching occupations. — Documented
8. Military Crosswalk maps codes/titles from Air Force, Army, Coast Guard, Marine Corps, Navy and Space Force (e.g., MOS "15W") to civilian occupations — useful for translating veterans' experience into civilian resume language. — Documented
9. Job Seeker Help points to American Job Centers (1-877-US2-JOBS / 1-877-872-5627; TTY 1-877-889-5627) and a ZIP-code locator — a free, human, public referral a bot can offer. — Documented
10. How a resume bot could use O*NET (my synthesis, not stated by O*NET as resume advice): (a) map the user's target or past job title to an O*NET-SOC code via keyword search or crosswalk; (b) pull Tasks/DWAs as vocabulary for describing duties the user actually did, then turn them into accomplishment bullets with the user's own results; (c) use Technology Skills, Hot Technology and In Demand flags to check which tools the user genuinely knows and should name explicitly (full name + acronym); (d) use Sample Reported Job Titles to recognize equivalent titles; (e) use Transferable Skills and Related Occupations for career changers; (f) always rank the actual job posting above O*NET, because O*NET describes an occupation in general, not a specific employer's requirements. — Inferred
11. Fabrication guardrail (inferred): O*NET lists what workers in an occupation may do or use; a bot must only add a task, skill or tool to a resume after the user confirms they have it — O*NET is a prompt for recall, not evidence of experience. — Inferred
12. Programmatic access exists (O*NET Web Services APIs, downloadable database) — relevant if a bot is given tool access; I did not read the API terms. — Documented (existence only)

## Limitations / bias
- O*NET is not resume advice; it says nothing about ATS, formatting or tailoring. All resume applications above are inferred.
- Occupation-level data describe typical workers, not a specific posting; job-posting technology counts depend on a commercial data vendor (Lightcast).
- I examined only one occupation report in detail; content varies by occupation.
- Some interactive features (search results, custom lists) are JavaScript-driven and were read only as static text.

## Best for
- A free, authoritative US government vocabulary source (tasks, skills, tools, job titles, military crosswalk) that a resume bot can use to prompt the user's recall and pick accurate keywords, without inventing experience.
