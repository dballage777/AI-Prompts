## Learned points
1. In Workday Recruiting, resume parsing lets recruiters create a prospect or a job application by attaching a resume. It works on the View Prospect report and in the tasks Create Confidential Prospect, Create Job Application, Create Prospect, Edit Prospect, and View Prospect, as well as on the prospect profile's Attachments tab. — Documented
2. Parsing populates fields from the resume, and Workday lets the user review the parsed data before saving. The workflow is "parse, then review," not silent auto-entry. — Documented
3. Fields that Workday does not auto-fill from a resume: Languages, Skills, and any fields configured as hidden. This means a resume's Skills section is not parsed into Workday's Skills field. Applicants or recruiters must enter skills separately, and the resume text remains the record. — Documented (the consequence for applicants is Inferred)
4. The page states that parsing results "can vary based on resume format and order of words." It recommends resumes without images or image-based styles. — Documented
5. Employers can configure job application templates to hide resume parsing for external candidates, so applicants for jobs that don't require resumes can apply faster. Parsing stays enabled for recruiters and for prospects who submit resumes through the "Prospect Introduce Yourself" page. Whether a candidate sees autofill depends on how each employer configures Workday. — Documented
6. The page links a "2021R1 What's New Post: Configurable Resume Parsing for External Job Applications," which dates configurable external parsing to Workday release 2021R1. No URL for that post was present to open. — Documented (title only)
7. The page does NOT state supported file types, file-size limits, supported languages, the parsing engine or vendor, or the full list of parsed fields (it says only "populates fields"). Those details could not be captured from this source. — Documented (absence)
8. The page says nothing about ranking, scoring, keyword matching, or auto-rejection. As documented here, parsing is a data-entry convenience. — Documented (absence); any claim that Workday parsing "rejects" resumes is not supported by this page — Inferred
9. Implication for a bot: produce a text-based, image-free, conventionally ordered resume so Workday-type parsers extract it cleanly. Tell users to check and correct autofilled fields on Workday applications, and to type skills and languages manually if prompted. — Inferred

## Limitations / bias
- This is a short vendor concept page last updated in 2023, written for administrators, not applicants. It omits file types, size limits, languages, and the field list. The detailed setup page is behind a Workday Community login.
- As vendor documentation, it describes intended product behavior, not measured parsing accuracy. Each employer's configuration varies.
## Best for
