## Learned points
1. The REST API base is `https://api.careeronestop.org`. Every request needs authentication through the header `Authorization: Bearer <API Token>`. Every path also includes a required `{userId}`. Responses are available as application/json or application/xml. — [Documented]
2. The Explorer's API families: American Job Centers, Apprenticeships, Boards and Committees, Certifications, Employment Patterns, Job Description Writer, Jobs V2, Labor Market Information, Licenses, Locations, Occupations, Occupations Reports, Professional Associations, ReEntry Programs, Salaries, Skills Gaps, Skills Matcher, State Resources, Tools and Technology, Training V2, Unemployment, and Youth Programs. — [Documented]
3. Jobs V2 List Jobs: `GET /v2/jobsearch/{userId}/{keyword}/{location}/{radius}/{sortColumns}/{sortOrder}/{startRecord}/{pageSize}/{days}`. Keyword can be text or an O*NET code (e.g., "nurse" or 29-1171.00). Location can be "reston, va", "VA", or a ZIP. Radius e.g. 25. Days e.g. 60, where 0 returns all jobs. SortColumns can be jobtitle, company, location, or acquisitiondate (0 for relevance). Optional query parameters: companyName, locationFilter, showFilters, enableJobDescriptionSnippet, enableMetaData. — [Documented]
4. Jobs V2 response fields: JobCount, TotalJobCount, ErrorMessage, and Jobs[] (JvId, JobTitle, Company, DescriptionSnippet, Distance, AcquisitionDate, URL, Location, Fc, OnetCodes). Facet lists cover Locations, Companies, and DatePosted. The meaning of the "Fc" boolean is not explained. — [Documented]
5. Job Details: `GET /v2/jobsearch/{userId}/{JvId}` with optional isHtml and enableMetaData. It returns JobTitle, Company, Location, Description, URL, AcquisitionDate, OnetCodes, and MetaData (Publisher, Sponsor, DataSource, DataSourceCitation, CitationSuggested, DataLastUpdate, DataVintageOrVersion, LastAccessDate). — [Documented]
6. AJC finder: `GET /v1/ajcfinder/{userId}/{location}/{radius}/{centerType}/{youthServices}/{workersServices}/{businessServices}/{sortColumns}/{sortDirections}/{startRecord}/{limitRecord}`. Filters default to 0. Sort can be Location (for a state), Distance (for a city, state, or ZIP), or Name. There are also Get AJC Details by ID and Get All AJCs. — [Documented]
7. Salaries: `GET /v1/comparesalaries/{userId}/wage?keyword=&location=` takes an ONET title or code and a city, state, ZIP, or national ("US, 0") location. It returns OccupationDetail with Wages split into NationalWagesList, StateWagesList, and BLSAreaWagesList (RateType, Median, etc.), plus WageYear and SocInfo. Compare-by-locations and compare-by-occupations variants also exist. — [Documented]
8. Occupations by keyword: `GET /v1/occupation/{userId}/{keyword}/{dataLevelOnly}/{startRecord}/{limitRecord}`. Optional datasettype takes onet, soc, socoes, or socmat. Optional searchby takes title or code (0 for keyword). — [Documented]
9. Occupations by Skills Match: `GET /v1/occupation/{userId}/{onetCode}/{location}/{radius}` with startRecord, pageSize, workPrefCodes (e.g., "2,6"), and enableMetaData. — [Documented]
10. Skills Matcher: `POST /v1/skillsmatcher/{userId}`. The body is an SKAValueList of {ElementId, DataValue} pairs, and the sample shows 40 entries. Sorting can be by rank, outlook, annualwages, typicaleducation, or occupationtitle (default rank), with an education filter. Skill element IDs come from "Get Skills" (not opened). — [Documented]
11. Skills Gaps (between two O*NET codes), Training V2 (programs and providers), Licenses, Certifications, Apprenticeship offices, and Unemployment (UI websites by state) are listed and relevant for referrals. They were not opened. — [Documented]
12. Many responses carry a MetaData block with Publisher, Sponsor, DataSource, and CitationSuggested. This suggests the API expects displayed data to be attributed. The actual citation rules sit on the blocked Technical Information page. — [Inferred]
13. Not shown on any Explorer page read: how to register or get a token and userId, rate limits, terms of use, where Jobs V2 postings come from, and how they are vetted. — [Documented] (absence)
14. For the bot: chain resume to O*NET code (S12 or Occupations keyword), then Jobs V2 by O*NET code and ZIP/radius/days, then show the posting URL and AcquisitionDate. Treat postings as aggregated listings that still need verification on the employer's own site (S11), and refer users to their nearest AJC for in-person help. — [Inferred]
