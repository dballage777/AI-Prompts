## Learned points
1. Krita is a free, open-source, cross-platform painting program for illustration, concept art, comics, textures, and animation. It is "not intended as a replacement for Photoshop." The manual can be downloaded as an EPUB. — Documented
2. DPI vs PPI: DPI is the printer's concern, and artists "should keep PPI in mind." Listed standards: 72 PPI (screen default), 120 PPI (low-quality posters), 300 PPI ("the minimum you should use for quality prints"), 600 PPI ("The quality used for line art for comics"). — Documented
3. For coloring pages, which are pure line art, working at 600 PPI (or at least 300 PPI) at final trim size follows Krita's guidance. — Inferred
4. New document (File > New, Ctrl+N): set dimensions, orientation, color model, bit depth, and resolution (PPI) in the Dimensions tab, or pick a Predefined size. Custom sizes can be saved as presets ("Save Image Size as"). Any .kra can become a template via File > Create Template from Image…. This is useful for a fixed page size across a whole book. — Documented (book use Inferred)
5. Image > Scale Image to New Size… changes the resolution (upres). For example, block in at 72 PPI, then switch to 300–400 PPI for detail. Image > Resize Canvas… (Ctrl+Alt+C) changes canvas size, with an offset that controls where space is added. — Documented
6. A line-art layer in grayscale can halve memory costs. Image > Convert Image Color Space converts all layers; Image > Properties changes only the image color space. — Documented
7. Anti-aliased brushes look smooth on screen but "might become fuzzy when printing." Slightly aliased brushes (for example, ink_tilt) give better print results. Any pixel brush can be made aliased with F5 > tick Sharpness. — Documented
8. Suggested split resolution: inking page at 600dpi and color page at 300dpi, so jaggies are less visible. — Documented (tutorial advice)
9. Super-thin lines: ink at double or triple size with an aliased pixel brush, then fill flats, split (Layer > Split > Layer Split), and resize down. The colorize mask cannot handle thin anti-aliased lines well. — Documented (tutorial advice)
10. Inking tips: draw long strokes from the shoulder/elbow; a stabilizer of "50 or so" smooths shake while keeping some irregularity; the Bezier Curve Tool and Assistant Tool (with Snap to Assistants) give smooth curves, but without line variation. — Documented (tutorial advice)
11. Sketch prep: put a white layer under the sketch, lower sketch opacity to about 10%, and ink on a layer above. Alternatively, tint the sketch (a color layer in screen/addition mode, or untick "blue" in layer properties). — Documented
12. PDF: Krita can open multi-layer PDFs, but "There is currently no PDF export, nor is that planned." The manual recommends Scribus for building PDFs from Krita images. It notes print houses often accept PDF. — Documented
13. Workflow implication: export each page as PNG (or TIFF) from Krita, then assemble the interior PDF in a layout tool (Scribus is suggested) for KDP or Lulu upload or an Etsy download. — Inferred
14. PNG is lossless, supports full alpha transparency, and suits grayscale images and "sharp contrasts, like comics", so it fits line art. JPG is suggested for images with many gradients. — Documented
15. File > Export… saves a flattened copy without switching the open document. PNG/JPG export uses the canvas background color (Image > Image Background Color and Transparency…) to fill transparency if transparency is not exported, so set white for printable pages. — Documented (white-background use Inferred)
16. Metadata stored includes author, creation date, description, DPI, and editing time (precision ±60 seconds). Author profiles are under Settings > Configure Krita > Author. — Documented
17. Command-line options --export, --export-filename, and --dpi exist (seen in the index only; details not read). These could allow batch export. — Documented (index only, summary-only)
