## Learned points
1. KDP limits how many new titles per format you can create and submit each week; both limits apply separately per format and reset every Sunday at 12:00 AM UTC. Exact numbers are not on this page (it points to "Create a Book"). — Documented
2. Interior file types: with bleed, the manuscript MUST be a PDF; without bleed, PDF, DOC, DOCX, RTF, HTML or TXT are accepted (KDP converts to PDF). — Documented
3. Cover: KDP Cover Creator (accepts JPG, PNG, GIF) or an uploaded PDF. — Documented
4. File specs: max 650MB; no emoji/unsupported special characters in file names; embed all fonts and images; flatten transparencies and layers; no crop marks, trim marks, bookmarks, comments, invisible objects, annotations, placeholder text, or metadata; all images (cover and interior) at least 300 DPI; optimize PDFs. — Documented
5. Listed "common points of failure" (rejection reasons): unflattened transparency/layers; locked/encrypted files; emoji/special characters in file names; crop/trim marks etc.; missing pages; excessive blank pages; title missing on front cover; barcode missing; incorrect pagination; PDF creation logos or watermarks. — Documented
6. Coloring-book relevance: "excessive blank pages" is a listed failure point, which matters for books that leave the back of each coloring page blank. The page does not define "excessive." — Documented (rule) / Inferred (relevance)
7. Cover size formulas: Cover Width = Bleed + Back Cover Width + Spine Width + Front Cover Width + Bleed; Cover Height = Bleed + Trim Height + Bleed; bleed = 0.125" (3.2 mm). — Documented
8. Cover formatting: one continuous image centered on the spine; flatten layers; 0.125" (3.2 mm) bleed on all sides (bottom bleed cannot exceed 0.125"); keep content not meant to be trimmed at least 0.25" (6.4 mm) from the outside cover edge; embed fonts. — Documented
9. Spine width per page: white paper page count x 0.002252" (0.0572 mm); cream x 0.0025" (0.0635 mm); groundwood x 0.00235" (0.0596 mm); color x 0.002347" (0.0596 mm). Worked example: 100-page 8.5x11 B/W white -> spine 0.2252"; cover = 0.125 + 8.5 + 0.2252 + 8.5 + 0.125 = 17.4752" wide x 11.25" tall. — Documented (factors) / Inferred (example arithmetic)
10. Spine text printed only on books with more than 79 pages; at least 0.0625" (1.6 mm) between spine text and spine edge; allow 0.0625" (1.6 mm) variance either side of fold lines. — Documented
11. Barcode: optional; if you don't supply one, KDP places one on the back cover automatically. — Documented
12. Interior: single-page files required (no spreads or 2-up). No-bleed page size = trim size. Full bleed: extend images 0.125" (3.2 mm) beyond trim on top, bottom and outer edges; PDF is 0.25" (6.4 mm) taller and 0.125" (3.2 mm) wider than trim. — Documented
13. Minimum font size 7 pt; embed fonts. Images: minimum 300 DPI, no hard maximum, but 600 DPI is the recommended maximum to keep total file size under 650MB (very high resolution can time out or delay manufacturing). — Documented
14. Pagination: sequential, even numbers on left pages / odd on right for LTR books; Roman numerals allowed for front matter. Page count is calculated from the file and rounded up to an even number; minimum 24 pages, maximum depends on ink, paper and trim. — Documented
15. Trim/page-count table matches S2 (e.g., 8.5x11: 24–590 B/W white, 24–550 cream, 24–578 groundwood, 72–600 standard color, 24–590 premium color; 8.27x11.69: standard color Not available). — Documented
16. Margins table matches S2: gutter 0.375"/0.5"/0.625"/0.75"/0.875" for 24–150/151–300/301–500/501–700/701–828 pages; outside at least 0.25" (no bleed) or 0.375" (bleed). — Documented
17. Grayscale fill: for black ink on white/cream with gray backgrounds, minimum recommended 10% fill. Line width: lines at least 0.75 pt or 0.01" (0.3 mm) thick — a key spec for coloring-book line art. — Documented
18. Reading direction: LTR for most languages; RTL paperback printing only in Hebrew, Yiddish and Japanese. All pages must share one orientation (some upside-down text allowed, e.g., riddle answers). — Documented
19. Inconsistency with S9: here spine text requires "more than 79 pages"; S9 says "at least 79" in places. S4 gives a groundwood spine factor; S9 does not. — Documented (observed)
