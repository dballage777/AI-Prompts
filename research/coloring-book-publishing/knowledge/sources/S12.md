## Learned points
1. There are two kinds of digital item. Instant downloads are ready-made files the buyer can access as soon as they buy. Made-to-order downloads are custom files made to the buyer's specification and sent when finished. — Documented
2. Digital items must be made and/or designed by the seller, the same rule as for handmade items. — Documented
3. To list one, create a normal listing and choose "Digital files" under "What type of item is it?". For made-to-order, set "When did you make it?" to "Made To Order". — Documented
4. An instant-download listing requires the files to be uploaded when you create it. You cannot publish or save an instant digital listing with no file attached. — Documented
5. File limits: up to five digital files per listing, with a maximum of 20MB each. — Documented
6. Supported file types: .bmp .doc .gif .jpeg .jpg .mobi .mov .mp3 .mpeg .pdf .png .psp .rtf .stl .txt .zip .ePUB .iBook. — Documented
7. For a coloring book, a multi-page PDF (or several PDFs or PNGs) fits the limits. A large book may need to be split across up to 5 files, or zipped, to stay under 20MB per file. — Inferred
8. Buyers see the file names exactly as uploaded, and names cannot be edited after upload. File names are limited to 70 alphanumeric characters, periods, underscores, or hyphens. Name files before uploading (for example, Ocean_Animals_Coloring_Pages_Part1.pdf). — Documented (example Inferred)
9. You can add one note for buyers that applies to all digital listings in the shop. Buyers see it on their Downloads page. This is a place for printing tips or license terms. — Documented (use Inferred)
10. Variations (for example, letter vs. A4 size options) cannot be offered for digital items. Different sizes need separate files in the same listing or separate listings. — Documented (workaround Inferred)
11. To change the file on an instant listing, remove it with the X icon and add new files with "Add files". — Documented
12. Canceling the order is the only way to revoke a buyer's access to a file after purchase. — Documented
13. Shops that sell only digital items can still be eligible for Star Seller. The dashboard leaves out the on-time shipping & tracking score. — Documented
14. To complete a made-to-order digital order: Shop Manager > Orders > New tab > check the order > Complete order > Upload file (up to five files, 20MB each) > Complete order. The buyer is notified by email. — Documented
