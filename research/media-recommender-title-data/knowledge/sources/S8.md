## Learned points
1. [Documented] Free, key-free REST/JSON API at `https://api.tvmaze.com` (HAL/HATEOAS). A separate user-level API exists for Premium members, and an Enterprise API is available for other licences or SLAs.
2. [Documented] Licence: "Use of the TVmaze API is licensed by CC BY-SA". The data "can freely be used for any purpose" if TVmaze is credited and ShareAlike is honoured. Linking back to TVmaze (e.g. with the API's URLs) satisfies attribution.
3. [Documented] Rate limit: "at least 20 calls every 10 seconds per IP address". Exceeding it may return HTTP 429; back off a few seconds and retry. Stricter temporary limits are possible. Leaving more than one idle connection open "may result in your IP getting blocked". A unique User-Agent is "strongly recommend[ed]".
4. [Documented] Caching: all output is cached for 60 minutes (allow up to 1 hour for edits to appear). `/schedule/full` and the show index are cached for 24 hours. Image URLs never change content and can be cached indefinitely.
5. [Documented] Search: `/search/shows?q=` is fuzzy (fuzziness 2), ranked by relevance, and returns full show info. `/singlesearch/shows?q=` returns exactly one result or none (fuzziness 1) and supports `embed`. With duplicate names (e.g. "Top Gear") "it's undefined which of them will be returned", so use `/search` to disambiguate.
6. [Documented] Lookup by external ID: `/lookup/shows?tvrage=`, `?thetvdb=`, `?imdb=`. Returns HTTP 301 to the show URL on a match, otherwise 404.
7. [Documented, live test] `curl -s -A 'MediaRecResearch/0.1 (research run)' -D - "https://api.tvmaze.com/lookup/shows?imdb=tt0903747"` returned `HTTP/2 301` with `location: https://api.tvmaze.com/shows/169`. Following it gave id 169 "Breaking Bad", type "Scripted", language "English", genres [Drama, Crime, Thriller], status "Ended", runtime 60, premiered "2008-01-20", network AMC (US), externals {tvrage 18164, thetvdb 81189, imdb tt0903747}. Use `curl -L` to follow the redirect.
8. [Research-like observation, live test] The show's `ended` field was "2019-10-11", not the finale date. `/shows/169/episodes?specials=1` returned 63 items, the last being "El Camino: A Breaking Bad Movie" (2019-10-11, type `significant_special`). The default list (no specials) returned 62 items, ending at "Felina" 2013-09-29. So `ended` can reflect a special or film, not the last regular episode. Verify run dates from the episode list.
9. [Documented] Episodes: `/shows/:id/episodes` is in airing order and excludes specials by default (`specials=1` adds "significant and insignificant specials"). Also available: `/shows/:id/episodebynumber?season=&number=`, `/shows/:id/episodesbydate?date=`, `/shows/:id/seasons`, and `/seasons/:id/episodes` (which always includes specials).
10. [Documented] Alternate lists: `/shows/:id/alternatelists`, `/alternatelists/:id`, `/alternatelists/:id/alternateepisodes` (embed `episodes`) for orders such as DVD. Live: `/shows/180/alternatelists` returned list id 1 "firefly-dvd-release" with boolean flags `dvd_release`, `verbatim_order`, `country_premiere`, `streaming_premiere`, `broadcast_premiere`, `language_premiere`.
11. [Documented] Other endpoints: `/shows/:id/akas` (`country` null = original country), `/cast`, `/crew`, `/images`. The paginated show index `/shows?page=` has 250 IDs per page by ID range; a 404 marks the end. `/updates/shows?since=day|week|month`.
12. [Documented] Schedules: `/schedule?country=&date=` covers only network or local web channels, not global ones like Netflix (use `/schedule/web`). The UK code is `GB`, not `UK`.
13. [Documented] Embedding: `?embed=episodes`, `?embed=nextepisode`, `?embed[]=episodes&embed[]=cast`.
14. [Inferred] TVmaze is the best key-free, LLM-safe (CC BY-SA) source for TV series status (Running/Ended), premiere dates, network or streaming channel, and episode lists, and for bridging IMDb↔TVDB↔TVmaze IDs. It covers TV only (no films), though some films appear as specials.

## Limitations or bias
- TV-only. Coverage is strongest for English-language and broadcast shows; anime coverage was not tested.
- No content ratings (certifications) were seen in the docs.
- ShareAlike may bind derived datasets you publish (it does not matter for purely personal use).
- Genres are TVmaze's own, coarse labels.

## Summary-only items
- None (the alternate-episode policy page linked from the docs was not opened).

## Best used for
- Key-free verification of TV shows by IMDb/TVDB ID, status, premiere/end, network, and episode lists. Alternate (DVD) orders via alternatelists.
