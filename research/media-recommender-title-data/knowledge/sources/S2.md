## Learned points
1. [Documented] AniList offers a free public GraphQL API, described as "a slightly trimmed down version of the API used by the site itself". All requests are POST to https://graphql.anilist.co with a JSON body holding `query` and an optional `variables`. Public media data needs no key. OAuth (authorization code or implicit grant) is needed only for user data and mutations.
2. [Documented] The rate limit is normally 90 requests per minute. A banner on the rate-limit page says the API "is currently in a degraded state and is limited to 30 requests per minute". Responses carry `X-RateLimit-Limit` and `X-RateLimit-Remaining`. Going over the limit returns HTTP 429 and a 1-minute timeout, with `Retry-After` and `X-RateLimit-Reset` headers. A separate burst limiter also exists, with no number given. Requests for higher limits are not being accepted right now.
3. [Documented] On stability, AniList may lower limits or suspend the API during outages. When the API is disabled it returns HTTP 403 with a GraphQL error message. In rare cases AniList manually blocks an IP that sends excessive requests.
4. [Documented] Terms: free for non-commercial use. Using the API "as a backup or data storage service" and "hoarding or mass collection of data" are prohibited (educational projects get leniency on the latter). It may not be used in competing list or tracker services. Apps with "AniList" in the name must add "UNOFFICIAL" or "for AniList". Commercial use is free under $150 per month in revenue; above that, a licence is needed.
5. [Documented] Adult content: `Media.isAdult` marks media "intended only for 18+ adult audiences". AniList warns that "Ecchi" shows are not counted as adult content, that its filtering cannot be guaranteed accurate, and that clients should add their own checks.
6. [Documented] Useful `Media` fields for verifying a title: `id`, `idMal` (cross-reference to MyAnimeList), `title{romaji english native}`, `synonyms`, `type` (ANIME/MANGA), `format`, `status`, `startDate`/`endDate` (FuzzyDate), `season`, `seasonYear`, `episodes` ("when complete"), `duration` (minutes), `chapters`, `volumes`, `countryOfOrigin` (ISO 3166-1 alpha-2), `isLicensed`, `source`, `genres`, `tags`, `relations`, `externalLinks`, `streamingEpisodes`, `nextAiringEpisode`, `averageScore`/`meanScore`, `popularity`, `recommendations`, `siteUrl`, `updatedAt`.
7. [Documented] `MediaFormat` values: TV, TV_SHORT (under 15 minutes), MOVIE (theatrical), SPECIAL, OVA, ONA, MUSIC, MANGA, NOVEL (light novels), ONE_SHOT. `MediaStatus` values: FINISHED, RELEASING, NOT_YET_RELEASED, CANCELLED, HIATUS (HIATUS is "Version 2 only").
8. [Documented] `MediaSource` is versioned. v1 has ORIGINAL, MANGA, LIGHT_NOVEL, VISUAL_NOVEL, VIDEO_GAME, OTHER. v2 adds NOVEL, DOUJINSHI, ANIME. v3 adds WEB_NOVEL, LIVE_ACTION, GAME, COMIC, MULTIMEDIA_PROJECT, PICTURE_BOOK. You opt in with `source(version: 3)`; otherwise newer source types collapse into the older values.
9. [Documented] `MediaTag` fields: `id`, `name`, `description`, `category`, `rank` ("relevance ranking of the tag out of the 100 for this media"), `isGeneralSpoiler`, `isMediaSpoiler`, `isAdult`, `userId` (the submitting user).
10. [Documented] A team curates the data with community submissions. The intro states "If the information cannot be traced back to a valid source, we don't list it" (credible sources: production companies, licensors, animators).
11. [Documented, live test] A key-free query works. Command: `curl -si -X POST https://graphql.anilist.co -H 'Content-Type: application/json' -d '{"query":"query{Media(search:\"Frieren\",type:ANIME){id idMal title{romaji english native} synonyms format status episodes seasonYear source(version:3) genres tags{name rank category isMediaSpoiler} isAdult countryOfOrigin}}"}'`. Result: HTTP/2 200 with header `x-ratelimit-limit: 30` and `x-ratelimit-remaining: 29`, which confirms the degraded 30/min limit as of 2026-11-14. The data returned id 154587, idMal 52991, romaji "Sousou no Frieren", English "Frieren: Beyond Journey’s End", native 葬送のフリーレン, format TV, status FINISHED, episodes 28, seasonYear 2023, source MANGA, genres [Adventure, Drama, Fantasy]. `search:` returned the first season (2023), not the 2026 second season, so a bare search picks one entry and the caller must check year and format.
12. [Documented, live test] Demographic labels appear as tags, not genres. Frieren's tags included `{"name":"Shounen","rank":71,"category":"Demographic"}`. Tag categories are hierarchical strings such as "Theme-Fantasy", "Cast-Traits", "Setting-Time", "Theme-Slice of Life". The spoiler flag works per tag: "Time Skip" (rank 82) had `isMediaSpoiler: true`.
13. [Documented, live test] `synonyms` mixes many languages and scripts (Korean, Thai, Russian, Arabic, Portuguese, etc.) and includes literal translations such as "Frieren at the Funeral". This makes it useful for matching user-typed titles.
14. [Inferred] Recommender use: verify a title with `Media(search:, type:ANIME)` or, better, `Page{media(search:)}` to see several candidates. Then confirm `seasonYear`, `format` and `countryOfOrigin`, and store `id` and `idMal`. Filter out tags with `isMediaSpoiler` (or `isGeneralSpoiler`) before showing them. Use tags with `rank` ≥ ~60 as descriptors. Treat `isAdult=false` as "not hentai", not as "family-safe".
15. [Inferred] At 30 requests per minute, batch many titles into one GraphQL request with aliases (for example `a:Media(id:..) b:Media(id:..)`) or `Page(perPage:50)`, and cache results within a session. The ban on hoarding means you should not mirror the database.

## Limitations or bias
- The docs give no update dates, so the "temporary" 30/min limit cannot be dated. It was confirmed live on 2026-11-14.
- Tags and their ranks are submitted and voted on by the community (`userId` field). Ranks show consensus, not an authoritative classification.
- Coverage leans Japanese. The brief did not ask for a coverage-size check, and none was made.
- Scores (`averageScore`, `meanScore`) reflect AniList's user base only.

## Best used for
- Key-free verification of anime and manga titles (romaji, English and native titles, year, format, episodes, status), getting the MAL cross-ID, ranked and spoiler-flagged tags including demographics, and source-material type.
