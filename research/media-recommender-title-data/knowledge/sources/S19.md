## Learned points
1. [Documented] Access requires a Twitch account with two-factor authentication. You register an app in the Twitch Developer Portal (OAuth Redirect URL "not used by IGDB", so enter `localhost`; Client Type must be "Confidential") and generate a Client Secret. No key-free access exists.
2. [Documented] Auth uses the client-credentials flow: `POST https://id.twitch.tv/oauth2/token?client_id=...&client_secret=...&grant_type=client_credentials` returns `access_token`, `expires_in` (seconds; example 5587808 ≈ 65 days), and `token_type: bearer`. Every request sends `Client-ID: <id>` and `Authorization: Bearer <token>`.
3. [Documented] Requests are mostly POST to `https://api.igdb.com/v4/{endpoint}`. The body uses Apicalypse syntax, e.g. `fields name,release_dates.human; search "Halo";` or `fields *; where id = 1942;`. `where version_parent = null` excludes editions. There is a multi-type `/v4/search` endpoint (characters, collections, games, platforms, themes). Browsers hit CORS errors, so call it server-side or from the CLI.
4. [Documented] Rate limits: "4 requests per second". Exceeding it returns `429 Too Many Requests`. At most 8 open requests at once.
5. [Documented] Licence/terms: "free for non-commercial usage under the terms of the Twitch Developer Service Agreement". Commercial partnerships go through partner@igdb.com. Code samples in the docs are "Program Materials" under that agreement. The agreement itself (on Twitch's site) was not read, so attribution or AI-use clauses are unknown here.
6. [Documented] Age ratings: `/v4/age_ratings` fields are `organization` (→ Age Rating Organization), `rating_category` (→ Age Rating Category, which has `organization` and `rating` string), `rating_content_descriptions` (→ Content Description V2 IDs), `rating_cover_url`, and `synopsis` ("A free text motivating a rating"). The older `category` and `rating` enums and `content_descriptions` are DEPRECATED.
7. [Documented] The deprecated enums show which bodies are covered: category ESRB 1, PEGI 2, CERO 3, USK 4, GRAC 5, CLASS_IND 6, ACB 7. Rating values include Three/Seven/Twelve/Sixteen/Eighteen (PEGI), RP/EC/E/E10/T/M/AO (ESRB), CERO_A–CERO_Z, and USK_0–USK_18 (the list continues). New code should resolve `rating_category` by ID instead.
8. [Documented] Game fields relevant to verification: `name`, `slug`, `first_release_date` (Unix timestamp), `game_type` (→ `/v4/game_types`; replaces the deprecated `category`), `game_status` (replaces `status`), `platforms`, `release_dates`, `alternative_names`, `external_games`, `parent_game`, `version_parent`, `remakes`, `remasters`, `expansions`, `standalone_expansions`, `dlcs`, `ports`, `bundles`, `similar_games`, `genres`, `themes`, `keywords`, `summary`, `storyline`.
9. [Documented] Ratings on a game: `rating` ("Average IGDB user rating"), `aggregated_rating` ("Rating based on external critic scores"), `total_rating` ("Average rating based on both IGDB user and external critic scores"), each with a `_count`.
10. [Documented] Franchises and collections: on a game, `franchise` is "The main franchise" and `franchises` lists "Other franchises the game belongs to". `collections` (array) replaces the deprecated single `collection`. A Collection ("AKA Series") has `games`, `name`, `slug`, `type` (→ Collection Type), and `as_parent_relations`/`as_child_relations` (→ Collection Relation, typed by Collection Relation Type with `allowed_parent_type`/`allowed_child_type`). Collection Membership Types have an `allowed_collection_type`.
11. [Inferred] Two-level grouping: franchise is the broad IP and collection is the series, and collections can nest via relations. Use `collections` plus `first_release_date` for release order. Remakes and remasters are explicit links, which helps avoid recommending duplicates.
12. [Documented] Data dumps (daily CSV for all endpoints) are "exclusively available to our Data Partners". Webhooks (`POST /v4/{ENDPOINT}/webhooks/` with `url`, `secret`, `method=create`) push create/update/delete events.
13. [Inferred, doc quirk] The `games.age_ratings` field description says "The PEGI rating", but the field is typed "Array of Age Rating IDs" and age ratings cover several organisations. Trust the type and filter by `organization`.

## Limitations or bias
- The Twitch Developer Services Agreement was not read (it is off-site), so terms on AI use, caching, and attribution are unknown.
- No live call was made (credentials needed).
- IGDB is user-contributed. User ratings may be sparse for older or niche games.
- Games only. It is relevant to a recommender only if games are in scope (e.g. anime-to-game adaptations).

- Verifying video games (existence, first release date, type, platforms) and their age ratings, franchise/series membership, and remake/remaster links.
