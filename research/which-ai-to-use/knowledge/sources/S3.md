## Learned points
1. Picks as of Oct 14, 2026: ChatGPT best overall; Claude for writing and coding; Gemini for Google products; Copilot for Microsoft products; Perplexity for internet deep dives; Meta AI for social media; DeepSeek for open-source reasoning; Grok for X integration; Poe for using multiple models; Duck.ai for data privacy; Pi for personal use. [Reported]
2. Core principle: "The answer depends on the actual task." Rebelo's examples: the best writing AI "may fall flat when fact-checking," and the best coding AI may be "too steerable." [Reported]
3. Selection criteria: AI intelligence (state-of-the-art models only), conversational experience (follow-ups, memory, adapting to instructions), available tools, usability and control (history, model switching), and unique features. [Reported]
4. How chatbots work: the app sends your prompt along with the conversation history, hidden instructions, and sometimes tool results. Many apps use several models (fast, complex, image). Developers tune settings, so the same underlying engine can give different results in different apps. [Reported]
5. ChatGPT: "over 1.2 billion weekly active users" (as reported by Zapier; the underlying source wasn't checked). Strengths: versatility, easy multimodal input, web search with thinking mode, Deep Research (up to about 20 minutes, with sources), Agent mode ("still a bit hit and miss"), Canvas, Projects, and custom GPTs. Listed con: "Uneven reliability when citing or sourcing information from the internet." Pricing: free, Go $8/month (with occasional ads), Plus $20/month. [Reported]
6. Claude (Haiku, Sonnet, Opus, Fable): engaging writing with logical flow, candid editing feedback when asked not to coddle, strong code (Claude Code, Artifacts), and connectors/MCP. Con: "Easy to hit token limits without careful context window management." Pricing: Pro $17/month billed annually, Max $100/month. [Reported]
7. Gemini: Workspace integrations, but these are "mostly searching through and returning data, not so much complex actions." Canvas can build apps that themselves call the Gemini API. Rebelo finds Deep Research output "more readable" than ChatGPT's. Gems work like custom GPTs. Con: "Response quality is inconsistent." Pricing: AI Plus $4.99/month, AI Pro $19.99/month. [Reported]
8. Copilot: built into Windows and Microsoft 365, using Microsoft Graph context (email, files, calendar) and Copilot Vision (screen sharing). Groups supports up to 32 people. Con: custom GPTs retired for regular users. Deeper 365 integration requires a Microsoft 365 subscription ($9.99–$19.99/month). [Reported]
9. Perplexity: research specialist with citations by default and Search, Research, and Labs modes. Con: "Better for factual research than creative or open-ended tasks." [Reported]
10. DeepSeek: free, open models that can be self-hosted. The hosted app is in China, raising privacy caveats, and it won't discuss topics such as Tiananmen Square. Self-hosting is suggested for privacy. [Reported]
11. Grok: real-time X data. Con: "Facing accuracy issues around several topics." Looser content policies. [Reported]
12. Poe: an aggregator that charges compute points and allows side-by-side comparisons and chained models. Rebelo says it is good for power users testing "which model handles a specific task best." [Reported]
13. Duck.ai: strips IP and metadata before prompts reach providers. Rebelo reports providers are contractually required to delete data within 30 days, with limited exceptions. He notes that personal data typed into a prompt is still visible to the providers. Fewer features. [Reported]
14. Method recommendation: "Test a few." All are free to try, and comparing how different apps handle the same question "will actually make you better at prompting your favorite one." [Reported]
15. Rebelo concludes there "isn't a wrong choice" among these chatbots, saying the real differences are interface, tools, and workflow fit. This contrasts with S1, which stresses capability gaps for high-stakes and agentic work. [Reported; contrast is Inferred]
16. Inferred for educators: running the same prompt across ChatGPT, Claude, and Gemini (or side by side in Poe) is a cheap way to choose a platform for a classroom task. Citation reliability needs checking, especially for ChatGPT web answers, per Zapier's listed con. [Inferred]
