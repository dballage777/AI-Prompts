## Learned points
1. SWE-bench tests whether an AI can fix real GitHub issues. Each entry reports "% Resolved", the percentage of task instances solved. The variants are: the original (2,294 instances, 12 Python repos), Verified (500, human-filtered), Bash Only (Verified 500 with every model in the same mini-SWE-agent environment), Lite (300, cheaper to run), Multilingual (300 tasks, 42 repos, 9 languages) and Multimodal (480 issues with visual elements). [Documented]
2. Verified was built with OpenAI. Human annotators checked that each problem description is clear, the test patches are correct, and the task is solvable from the information given. [Documented]
3. There is a key distinction between the full leaderboard and Bash Only. The full leaderboard compares whole systems ("simple LM agent loops to RAG systems to multi-rollout and review type systems"). Bash Only compares models: a bare ReAct loop with only a bash shell, with "no tools, no special scaffold structure." Harness choice changes scores, so system scores and model scores should not be compared directly. [Documented]
4. Bash Only versions are not fully comparable with each other. mini-SWE-agent 1.x and 2.x differ (2.x uses tool calling, and temperature is 0 in 1.x but unset in 2.x). The team says it does not tune the setup to push scores higher. [Documented]
5. Top Verified Bash-Only results (embedded data, mini-SWE-agent 2.0.0, Feb 2026): Claude 4.5 Opus (high) 76.8% at about $0.75 per instance; Gemini 3 Flash (high) 75.8% at about $0.36; MiniMax M2.5 (high, open weights) 75.8% at about $0.07; Claude 4.6 Opus 75.6% at about $0.55; GLM 5 (high, open) 72.8%; GPT 5.2 (high) 72.8%; GPT 5.2 Codex 72.8%; Claude 4.5 Sonnet (high) 71.4%; Kimi K2.5 (high, open) 70.8% at about $0.15; DeepSeek V3.2 (high, open) 70.0%. [Documented]
6. The top of Verified has bunched up. About ten models from five or more labs score between 70% and 77%. Open-weight models (MiniMax, GLM, Kimi, DeepSeek) are within a few points of the closed leaders at a fraction of the cost. [Inferred from point 5]
7. Top of the full Verified leaderboard (systems): Sonar Foundation Agent + Claude 4.5 Opus 79.2%; live-SWE-agent + Claude 4.5 Opus 79.2%; TRAE + Doubao-Seed-Code 78.8%; live-SWE-agent + Gemini 3 Pro Preview 77.4%. Most top system entries are marked not verified by the SWE-bench team. [Documented]
8. Multilingual board (Feb 2026, team-checked runs): Gemini 3 Flash 72.7%, Claude 4.6 Opus 72.0%, Claude 4.5 Opus 70.7%, GLM 5 69.7%, Gemini 3 Pro 68.7%, MiniMax M2.5 68.3% (total cost about $30 vs about $199 for Opus 4.6), GPT 5.2 (high) 66.7%, DeepSeek V3.2 59.0%. [Documented]
9. Harder variants still have much lower scores. The top Multimodal score is about 36% (GUIRepair + o3; Codefuse). The top on the full 2,294-instance set is 52.6% (Sonar + Claude 4.5 Opus). [Documented]
10. The leaderboard data is stale for Nov 2026. No entries after Feb 2026 appear, even though model families such as Claude Opus 5.x and GPT-6 exist by this date according to other sources in this project. Readers should check the date of any SWE-bench claim. [Documented (dates); Inferred (staleness)]
11. Integrity check (blog, 19 Nov 2025): the team measured how often submitted patches exactly contain the gold patch. The average was 6.7% on Verified (excluding one outlier), 4% on Lite and 2.45% on the full set. One suspicious entry (Honeycomb) turned out to be a submission error. Going forward, submissions with exact-match rates above 20% will be questioned. [Documented]
12. Cost-vs-performance post (8 Aug 2025) on mini-SWE-agent: GPT-5 matched Claude Sonnet 4 but was cheaper; Claude Opus 4 was "still unbeaten" at the time; GPT-5-mini gave up about 5 points for much lower cost; GPT-5-nano gave "half for half the performance." Vendor launch numbers can come from different harnesses (OpenAI used Agentless), so they differ from Bash-Only numbers. [Documented]
13. The site also offers analysis views such as resolved vs cost, by repository and language, and by step or cost limit. The SWE-bench family has newer evaluations: CodeClash (Nov 2025, goal-oriented development) and ProgramBench (May 2026, building software from scratch). This suggests the team sees issue-fixing benchmarks as nearing saturation. [Documented; interpretation Inferred]
14. For non-coders such as teachers, SWE-bench is relevant only for coding and agentic tool choice. A gap of 1–3 points among the top models is small next to differences in cost and harness. [Inferred]

## Limitations
- I read the leaderboard numbers from the embedded JSON. The rendered table's default sorting and filters may differ, and the costs are my per-instance figures from the `instance_cost` field.
- Data ends Feb 2026 and has no entries for the newest 2026 models.
- Many full-leaderboard entries are self-reported and unverified.
- The SWE-bench paper (arXiv 2310.06770) and OpenAI's Verified post are off-site and were not read.
