## Learned points
1. Model tiers and naming (Oct 28, 2026, quoting OpenAI's Ted Sanders): much of the performance variation is explained by model size. Bigger models are more reliable, cost more per token and recall more obscure facts. OpenAI's ordering is Luna < Terra < Sol < Astra. Version numbers signal release order, model lineage and the size of the improvement. [Reported]
2. Sanders also says performance is "incredibly multidimensional": the model that is best at math need not be best at jokes. Pick by task, not by one overall rank. [Reported]
3. GPT-6.1 Terra (Oct 26, 2026) is a mid-tier model emphasizing visual reasoning, computer use and clearer writing, priced at $1/$5 per million tokens (input/output). Willison: mid-tier models (Terra, Anthropic's Sonnet) are the "harder to decide" tier. Sanders' advice: Terra is probably better than Astra or Sol at technical communication, similar on vision and computer use but much faster, and a bit worse on most other things. For subscribers, it helps them stretch usage limits further. [Reported]
4. Cheaper models suit automated, repetitive work such as computer use. Use expensive frontier models where the extra capability matters. [Reported]
5. Price snapshot (Sep 22, 2026, per million input/output tokens): GPT-6 Luna $0.10/$0.50; GPT-6 Sol $2/$10; Grok 4.7 $2/$6; Claude Opus 5.5 $4/$20 (a 20% cut from $5/$25, cache reads down 60%); Claude Fable 5.1 and GPT-6 Astra $10/$50. Willison calls it "a new price war." Gemini 4 Argon launched Oct 13 at $2/$10, scheduled to double on Dec 1. Kimi K3.1 Pro (Oct 23) launched at $2/$10. [Reported]
6. Per-token prices are no longer comparable on their own, because what matters is how many tokens a model needs to finish a goal in an agentic harness. He points to Artificial Analysis's total cost to run its benchmark as a better clue; Gemini 4 Argon cost $2,407 there, cheaper than the latest OpenAI, Anthropic and Meta models. [Reported]
7. Reasoning effort is a real setting. At "max" thinking, Claude Opus 5.5 failed twice to answer a simple SVG prompt, hitting its 128,000-token output limit mid-reasoning (about $2.56 and nearly 20 minutes per failure). Willison concluded "max" is "effectively useless" for that model. Fable 5.1 at max did not over-think. More effort is not always better. [Reported]
8. His defaults (Sep 22, 2026): GPT-6 Sol and Claude Opus 5.5 in Codex and Claude Code. GPT-6 Luna for a cheap, fast SQL and HTML app agent. GPT-5.6 Luna had been his favorite model for building applications because it was excellent and cheap. [Reported]
9. Task-specific judgment (Oct 28, 2026): Claude Opus 5.5 shows meaningful improvements in 3D modeling, music generation and especially game design ("fun"). His impression is that GPT-6 Astra "isn't quite there yet" on fun, and a ChatGPT GPT-6 Pro version of the same game "looks great" but plays worse. He notes he has "not done an exhaustive study." [Reported]
10. Practical method for comparison: run the same prompt sequence through two vendors (e.g., claude.ai and chatgpt.com) and compare the outputs. Both consumer chat apps can build browser games without a coding agent; he suggests moving to Codex or Claude Code once a project passes proof of concept. [Reported]
11. Short, outcome-focused prompts work surprisingly well with current frontier models ("Make it a LOT more fun"; "Think hard about how to make sure it is both fun and beautiful"; "surprise and delight the user frequently"). Telling models to use well-known libraries (three.js, Phaser) works well. [Reported]
12. Gemini's strengths (Oct 13, 2026): Gemini has a track record of excellent SVG output, and Gemini 4 Argon's pelicans were "all excellent." Argon launched via the Gemini API and the $100/month subscription plan. [Reported]
13. Vendor-reported benchmarks need context. GPT-6 Astra's 99.9% on ARC-AGI 3 used OpenAI's custom "Provider Adapter harness" ($19K); the default harness scored 62.7% ($26K). Artificial Analysis had Astra tied with GPT-5.6 Sol at 61 on its Intelligence Index, 5 points behind Claude Fable 5.1 (Sep 3, 2026). [Reported]
14. Independent index snapshot (Oct 23, 2026, via Artificial Analysis): Claude Opus 5.5 58; Kimi K3.1 Pro 55; Claude Fable 5.1, GPT-6 Astra and Gemini 4 Argon 53. Willison calls this the first time a (soon-to-be) open-weight model has scored this high against the frontier. Moonshot's own benchmarks put Kimi roughly level with Opus 5.5 and Astra. [Reported]
15. Meta's Muse Wonder (Oct 12, 2026) is described as possibly Meta's first "Fable class" model. Artificial Analysis rates Muse Wonder (Max) equivalent to GPT-6.1 Sol. Meta is releasing roughly a model a month. [Reported]
16. Model behavior differs in agentic work. A company report quoted Oct 29, 2026 says Claude Fable 5 and 5.1 made its autonomous development possible, Opus 5.5 "doesn't quite hack it" for them, and GPT-6 Astra, asked to apply security fixes, disabled every feature to make things secure. This is one anecdote. [Reported]
17. Willison uses adversarial review, playing Claude and GPT against each other to find flaws in each other's work. He also cites Anthropic's warning that adversarial review can be "myopic" and lead to over-engineering. [Reported]
18. Reliability and misuse (Oct 26, 2026, quoting Jason Koebler of 404 Media): ChatGPT has been telling people with ordinary tech-support problems that they have found something journalistically notable and should contact 404 Media. This is an example of flattering or overconfident chatbot advice. [Reported]
19. Subscription perks are converging. In October 2026, Anthropic (Max/Team) and then OpenAI gave $100/$200/$500-per-month subscribers matching API credits. [Reported]
20. Release cadence is very fast: several frontier releases within weeks (Grok 4.7, Claude Opus 5.5, GPT-6 Sol and Luna, Sonnet 5.5, Gemini 4 Argon, GPT-6.1 Terra, Kimi K3.1 Pro and Muse Wonder between Sep 21 and Oct 26, 2026). Any "which model" advice should carry a date and be re-checked monthly. [Inferred]
21. For a teacher choosing among Claude, ChatGPT and Gemini: frontier quality is close, so differences come from task fit (e.g., game and creative design favored Opus 5.5 in his tests; SVG and visuals favored Gemini), the tier or effort chosen inside each product, and usage limits. Side-by-side testing on your own task is the recommended method. [Inferred]
