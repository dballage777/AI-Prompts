## Learned points
1. [Documented] The roadmap is explicitly "aspirational"; plans may shift during the year, and it "primarily reflects the work our teams at Google are focusing on." Both the 2025 and 2026 posts state that non-Google contributors now outnumber Google-employed contributors. The detailed roadmap lives on GitHub (not read; github.com blocked for this run).
2. [Documented] Impeller: in 2026 Flutter is "completing the migration to the Impeller renderer on Android," removing the legacy Skia backend on Android 10 and above, to reduce jank. Flutter 3.29 (Feb 2025) had "big Impeller updates."
3. [Documented] Web: aim for WebAssembly (Wasm) to become the default for Flutter web. Platform commitment: "day-zero support for Android 17 and upcoming iOS releases"; desktop multi-window with Canonical.
4. [Documented] AI developer experience: Google will keep Dart/Flutter "top-tier" in Gemini CLI and Antigravity, including stateful hot reload working with AI agents, and is "investing in MCP (Model Context Protocol) servers for Dart tooling" so agents can refactor and pick libraries by talking to the Dart analyzer.
5. [Documented] 2025 AI deliverables: the Dart and Flutter MCP server was introduced in Flutter 3.35/Dart 3.9 (Aug 2025) and is "now stable"; a Flutter Extension for Gemini CLI; Gemini in Android Studio supports Dart/Flutter; Flutter AI Toolkit v1.0 (widgets for GenAI features, migrated to Firebase AI Logic SDK, multi-turn function calling); "Create with AI" docs section. Named agent tools are all Google's (Gemini CLI, Antigravity); Claude Code is not mentioned on these pages.
6. [Documented] GenUI/agentic apps: Flutter GenUI SDK (alpha on pub.dev as of Dec 2025) and A2UI protocol for model-generated UI. Dart is investigating interpreted bytecode in the runtime for "ephemeral" code delivery — loading parts of an app on demand "without requiring a full app store update."
7. [Documented] Governance/sustainability: decoupling Material and Cupertino into standalone packages (announced in 3.35, "underway"); making the engine extensible so new platforms can be built "out-of-tree"; expanding Consultancy Program, Insiders, GDE network, Customer Advisory Board, and Partners Advisory Board.
8. [Documented] Dart language 2026: plan to ship Primary Constructors and Augmentations ("to simplify code generation"), keep improving build_runner and Dart/Wasm compilation, refactor the analyzer for large apps. 2025: build_runner made "two or more times" faster in some cases; Dart 3.10 dot shorthands; Dart 3.8 null-aware elements; new Dart formatter in 3.7.
9. [Documented] Release cadence: "Dart and Flutter ship quarterly updates"; 2025 stable releases were Flutter 3.29/Dart 3.7 (Feb), 3.32/3.8 (May), 3.35/3.9 (Aug), 3.38/3.10 (Nov) — the post calls these "eight packed stable releases" (four Flutter + four Dart).
10. [Documented] Flutter 3.38 (Nov 2025) delivered "crucial iOS 26/Xcode 26 support and the UIScene migration path"; Flutter 3.35 made web hot reload default and launched experimental Widget Previews (IDE integration in 3.38).
11. [Documented] Full-stack Dart: Dart Cloud Functions for Firebase (~10 ms cold starts claimed), investigating Dart for Google Cloud SDK, Genkit Dart support.
12. [Reported] Adoption claim (Google I/O, as repeated by the Flutter team): "nearly 30% of new free iOS apps are built with Flutter"; showcase apps include NotebookLM (4.8-star app in under 7 months), talabat, teamLab, GE Appliances.
13. [Documented] Ecosystem services named: Shorebird for over-the-air updates, Serverpod backend, dartantic_ai multi-model agent framework (community).
14. [Documented] Macros: none of the three pages mention Dart macros; the 2026 plan lists "Augmentations to simplify code generation" and build_runner work instead. Whether macros were dropped is not stated here.
15. [Inferred] Funding/maintenance signal: Flutter remains Google-led (roadmap is Google's team plan) with growing outside contributors and formal advisory boards; no foundation transfer is mentioned — contrast with React's move to a foundation (S20).
16. [Inferred] For a Claude Code workflow, the official Dart/Flutter MCP server is usable by any MCP client, but Google's stated optimization targets are Gemini CLI and Antigravity; agent support for Claude Code must be checked in docs, not assumed from these posts.
17. [Inferred] Quarterly releases plus Impeller/Skia removal and Material/Cupertino package split imply some migration work over the next year for any Flutter app.
