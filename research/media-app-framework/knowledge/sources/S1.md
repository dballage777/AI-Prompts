## Learned points
1. [Documented] The React Native docs recommend starting new apps with a framework, and they name Expo: "most developers benefit from using a React Native Framework like Expo." The listed reasons are file-based routing, universal libraries, and plugins that change native code "without having to manage native files."
2. [Documented] The docs' new-project command is `npx create-expo-app@latest`. They call Expo "a production-grade React Native Framework" that is "free and open source". They also say the Expo team "works in close collaboration with the React Native team at Meta" and that EAS is "an optional set of services".
3. [Documented] You can use React Native without a framework, but the docs warn that you then either write your own solutions for navigation, native APIs and native dependencies, or assemble libraries into "a skeleton of a Framework". They say this "takes real work, both when starting your app, then later when maintaining it."
4. [Documented] You only need to set up a local environment (Android Studio, Xcode) if you skip the framework: "Setting up your environment is not required if you're using a Framework… it will take care of building the native app for you." Installing the tools from scratch is estimated at "about an hour".
5. [Documented] The key no-Mac rule: in the Linux and Windows dev-OS tabs, the iOS target is marked "Unsupported" with the note "A Mac is required to build projects with native code for iOS. You can use Expo Go from Expo to develop your app on your iOS device."
6. [Documented] iOS setup on macOS needs Node, Watchman, the RN CLI, Xcode (the latest version, from the Mac App Store; this also installs the iOS Simulator) and CocoaPods, a Ruby gem. Since RN 0.69, a `.xcode.env` file sets `NODE_BINARY` for Xcode build phases.
7. [Documented] Android setup works on Linux: Node 22.11.0 or newer, JDK 17 ("You may encounter problems using higher JDK versions"), Android Studio, and specifically the Android 15 (VanillaIceCream, API 35) SDK. Emulator AVDs use the API 35 image. VM acceleration is recommended.
8. [Documented] The no-framework path uses `npx @react-native-community/cli@latest init AwesomeProject`, then Metro (`npm start`), then `npm run android`. If you previously installed the global `react-native-cli`, remove it first. A specific version is pinned with `--version X.XX.X`. Ignite CLI is named as a third-party alternative. iOS troubleshooting uses `bundle install` and `bundle exec pod install`.
9. [Documented] The docs describe Metro as "the JavaScript build tool for React Native", similar to Vite or webpack and using Babel. Reload in the app by pressing R twice or using the Dev Menu (Ctrl+M).
10. [Documented] The nav sidebar lists "Out-of-Tree Platforms" (Web, Windows, visionOS are linked) and marks "Building For TV Devices" with a deprecation (trash) icon.
11. [Inferred] For this project (Linux container, no Mac, Claude Code), plain React Native without a framework cannot produce iOS builds at all. Any RN route to iOS has to go through Expo (or another framework) plus a cloud macOS build service (see S2). Android-only local work (emulator, Gradle builds) is possible on Linux if the container can run Android Studio or an emulator, which is not guaranteed in a sandbox.
12. [Inferred] The docs mention Expo Go for "develop on your iOS device". Expo Go only runs code that uses the libraries bundled in Expo Go. A monetized app with in-app subscriptions and a custom video player will likely need a development build instead (see S2). The RN page itself does not say this.

## Limitations or bias
- These are getting-started pages. They say nothing about performance, video or payment libraries, release cadence, or AI tooling.
- The RN docs endorse a single commercial-backed framework (Expo). That is a policy statement by Meta's RN team, not a neutral comparison.
- "Expo Go for iOS device" is mentioned without its limits (no custom native code). Those limits are documented by Expo, not here.
- Version numbers (Node 22.11.0, JDK 17, API 35) apply to the RN 0.88 docs dated Oct 27, 2026 and will drift.
