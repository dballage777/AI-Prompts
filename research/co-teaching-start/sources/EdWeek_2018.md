# Education Week (2018): "What It Takes to Make Co-Teaching Work." S. Schwartz
URL: https://www.edweek.org/teaching-learning/what-it-takes-to-make-co-teaching-work/2018/12 | Access: OPENED | Published: Dec 5, 2018
Type: journalism. It quotes Marilyn Friend (co-teaching expert) and Sara Cook (researcher), and profiles an elementary team.
## Key points (Reported)
- Teacher Lauren Eisinger: "underneath everything, you need to trust each other."
- Friend: teachers need "the time, training, and resources." Co-teaching should be "more like a business partnership." Parity matters (for example, co-signed emails, both names displayed). The two teachers are equals but have different roles: content expertise vs. the IEP plan.
- Cook: findings on student outcomes are "mixed." CEC's 2018 practice recommendations suggest proceeding with caution.
- "Time: The Key Component." The featured team gets one shared 40-minute planning period a week, which leaders scheduled intentionally, plus a half day for planning.
## Quotes
- "You need to be very flexible, and underneath everything, you need to trust each other"
- "It really needs to be more like a business partnership."
